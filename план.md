## 1. Сравнительный анализ: Статус реализации бизнес-требований

| Бизнес-требование | Статус | Примечание |
| :--- | :---: | :--- |

| **Количество БК: 150+ (СНГ, Азия, Африка)** | 🔶 В работе | 29 БК активны, часть парсеров сломана (см. non_working_bookmakers.md) |

| **Функция "Близкие коэффициенты" (Close Odds)** | ❌ Не начато | Нужен эндпоинт в `aggregator-api` и UI в карточке вилки |
| **Встроенный браузер и автопростановка купонов** | ✅ Базовая | Chrome Extension: Fonbet, Winline, Marathonbet, Betcity |

| **Заморозка подписки** | ✅ Готово | `SubscriptionService.freeze/unfreeze` + UI в SettingsModal |
| **Интеграция с Telegram-ботом (сигналы по фильтрам)** | ✅ Готово | `NotificationScheduler` каждые 30с: вилки, валуи, коридоры |
| **Двухуровневая реферальная система (Revenue Share)** | ✅ Готово | `BaseReferralController` + страница `/affiliate` + виджет |

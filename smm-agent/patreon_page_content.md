## 🎁 Freebet Math (Our Core Methodology)

Every SNR (Stake Not Returned) freebet is worth **≈80% in guaranteed cash** via matched betting:

```
η = (K₁ - 1)(K₂ - 1) / K₂ ≈ 0.80
where:
  K₁ = main bookmaker odds (target: 4.5–6.0)
  K₂ = lay/exchange odds   (target: 1.20–1.28)
```

**Example:**

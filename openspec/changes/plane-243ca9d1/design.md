# Design: [team-national-detect] Автоматическое распознавание национальных сборных, связывание с ISO-кодами стран и бекфилл БД

## Context
See `proposal.md` - Context & Description.
Plane Task ID: `243ca9d1-f4a5-4a33-9c9c-43656b22da1e`
Feature Branch: `feature/plane-243ca9d1`

В исторических данных агрегатора накоплены тысячи записей команд, у которых не классифицирован признак национальной сборной (`is_national_team`), отсутствуют коды стран ISO-3166 и ссылки на векторные флаги. Для корректной агрегации и отображения матчей сборных на портале и в API необходим автоматический распознаватель, встроенный в сквозной пайплайн нормализации и бекфилла.

## Goals / Non-Goals

**Goals:**
- Создать справочник стран и ISO-кодов `CountryIsoRegistry` с поддержкой Alpha-2/Alpha-3, мультиязычных названий (RU/EN), синонимов и ссылок на векторные флаги SVG.
- Реализовать эвристический детектор `NationalTeamDetector` для распознавания сборных команд, выделения возрастных категорий (`U23`, `U21`, `U20`, `U19`, `U18`, `U17`, `OLYMPIC`, `YOUTH`) и пола (`MALE`, `FEMALE`), с очисткой клубных префиксов и шумовых суффиксов.
- Реализовать `NationalTeamBackfillService` для пакетной классификации и бекфилла базы данных команд с поддержкой режима `dryRun`, фильтрации по виду спорта и ограничению размера выборки.
- Интегрировать `NationalTeamDetector` и `NationalTeamBackfillService` в `HistoricalTeamBackfillService` для сквозной нормализации, дедупликации и слияния вариантов названий сборных в каноническую запись.
- Реализовать REST API в `DataManagementController` (`/teams/backfill-national-teams` и `/teams/detect-national`).

**Non-Goals:**
- Изменение алгоритмов парсинга коэффициентов в краулерах (краулеры передают сырые строки от букмекеров).
- Ручной ввод соответствий для каждой команды (процесс полностью автоматизирован).

## Decisions

- **Decision 1: CountryIsoRegistry со встроенной таблицей стран и флагов**:
  Справочник загружается в память и обеспечивает мгновенный поиск O(1) по Alpha-2, Alpha-3, русским и английским названиям стран и их синонимам.
- **Decision 2: Регулярные выражения и эвристики в NationalTeamDetector**:
  Детектор извлекает возрастные категории, гендерные маркеры, отсекает клубные префиксы (ФК, БК, ХК и т.д.) и формирует каноническое отображаемое имя (например, "Испания", "Германия U21", "США (жен)").
- **Decision 3: Сквозная дедупликация в HistoricalTeamBackfillService**:
  Команды сборных группируются по ключу вида спорта, ISO-кода страны, возрастной категории и пола. Все дубликаты (например, "Spain", "Сборная Испании") объединяются в каноническую команду с сохранением исходных названий в `TeamAlias`.
- **Decision 4: Безопасный режим бекфилла (dryRun)**:
  Эндпоинт `/teams/backfill-national-teams` поддерживает `dryRun=true` для предварительной оценки объема изменений без изменения данных в БД.

## Risks / Trade-offs

- **[Risk] Ложные срабатывания на клубах с географическими названиями (например, "ФК Россиянка")** → Mitigation: Клубные префиксы ("ФК", "FC", "БК" и др.) без явных маркеров сборной блокируют распознавание как сборной.
- **[Risk] Слияние разных возрастных категорий одной страны** → Mitigation: Ключ группировки включает `ageCategory` и `gender`, исключая объединение основной сборной и U21.

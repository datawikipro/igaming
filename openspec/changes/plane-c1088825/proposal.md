# Proposal: [feedback-admin-ui] Единая админ-панель обратной связи в smartbet.guru (/admin/feedback)

## Context
Plane Task ID: `c1088825-05dd-4d32-aff9-91dea84a507a`
Module: Patron CRM & Community Feedback Hub (SmartBet.guru)

## Description
Разработка современного, реактивного интерфейса единой админ-панели **Feedback & Patron Desk** в веб-приложении `smartbet.guru` (Next.js 14, Tailwind CSS, TypeScript, Lucide Icons) по адресу `/[locale]/admin/feedback`.

Панель объединяет входящий поток пожеланий, баг-репортов и вопросов пользователей из всех каналов (Boosty, Patreon, VK Donut, Telegram VIP, Web, Threads, Reddit) с акцентом на приоритетное обслуживание платных патронов (SLA 15 минут для VIP), AI-суммаризацию, генерацию персональных ответов и сквозное создание задач в Plane в 1 клик.

## User Impact & Capabilities
- **Метрики в шапке дашборда**:
  - Текущий MRR от платных каналов (Boosty + Patreon + VK Donut + TG VIP)
  - Количество открытых VIP-тикетов с таймером обратного отсчета SLA
  - Количество внедренных пожеланий донатеров
  - Размер общего бэклога идей
- **Визуальная дифференциация карточек**:
  - Золотая плашка VIP-патрона: градиентный бейдж `[💎 BOOSTY PRO — 2 500 ₽/мес | LTV: 17 500 ₽]`, ссылка на профиль, приоритет P1/P2.
  - Серая плашка Free: бейдж `[⚪ БЕСПЛАТНЫЙ: Threads @vasya]`.
- **Табы и фильтры**: «🔥 Только донатеры (P1/P2)», «💡 Пожелания (Фичи)», «🐛 Баги», «❓ Вопросы», «🌐 Бесплатные соцсети», «✅ Решенные», поиск по ключевым словам и авторам.
- **Действия в карточке**:
  - Кнопка `[🚀 В один клик в Plane]` — открытие предзаполненной модалки создания задачи.
  - Кнопка `[⚡ Сгенерировать AI-ответ]` — генерация и редактирование персонального ответа патрону.
  - Кнопка `[💬 Ответить в Boosty/TG]` — модалка прямой отправки ответа в соответствующую платформу.
  - Кнопка `[Перевести в архив / Решено]` — быстрое изменение статуса тикета.
- **Интеграция в админ-панель**: добавление карточки "Обратная связь и Патроны" в общее меню `/[locale]/admin`.

## 2. Основной сайт (`smartbet.guru`)

### 2.1 Назначение и стек
Полнофункциональный веб-портал для анализа спортивного арбитража, сравнения коэффициентов, ведения учета ставок и привлечения реферального трафика.
* **Стек**: Next.js 14 (App Router), TypeScript, Framer Motion, Vanilla CSS / Tailwind, next-intl (локализация RU/EN).

### 2.2 Функциональные возможности
* **Сетки арбитража**: Страницы для прематч/лайв вилок (`/arbs`), ставок с перевесом (`/valuebets`) и коридоров (`/middles`).
* **Калькулятор Келли и EV**: Математическое ядро, позволяющее рассчитывать размер ставки по критерию Келли с учетом очищения коэффициентов от маржи Pinnacle. EV-индикатор меняет цвет (Glowing Gauge) с красного на зеленый при положительном EV.
* **SEO-воронка**: Ограничения для гостей. Неавторизованные гости видят те же вилки, что и авторизованные пользователи без подписки (до 5.0% прибыли, без искусственных задержек на уровне API), но не могут использовать демо-кошелек и сохранять предпочтения по регионам/букмекерам в профиле. Рендерится промо-баннер, предлагающий авторизоваться и вызывающий `AuthModal` при клике.
* **Справочник букмекеров (`/bookmakers`)**: Каталог обзоров букмекерских контор с E-E-A-T текстами, рейтингами, копированием промокодов в клипборд и адаптивным сайдбаром с реферальными ссылками.
* **Детализация матчей (`/matches/[slug]`)**: Интерактивная матрица сравнения коэффициентов от разных БК, графики изменения котировок в реальном времени и прогнозы на основе ИИ.
* **Бухгалтерский модуль (`/wallet`)**: Виртуальный кошелек, позволяющий игрокам управлять своими балансами у разных букмекеров и автоматически списывать средства при фиксации ставки.
* **Партнерская система (`/affiliate`)**: Двухуровневая реферальная система (Revenue Share) с генерацией iframe-виджета для партнеров.

### 2.3 Текущий статус
* 🟢 **Что работает**:
  * Калькулятор критерия Келли и EV в [SurebetCalculator.tsx](file:///C:/Users/chernousov_a/WebstormProjects/igaming/smartbet.guru/src/components/SurebetCalculator.tsx).
  * Воронка лимитов для гостей на главной странице.
  * Каталог букмекеров и страницы детальных обзоров с динамическими SEO-метаданными.
  * Виртуальный кошелек с поддержкой списания ставок из ValueBets и Middles.
  * Реферальная программа с iframe-виджетом.
* 🔴 **Что НЕ работает / в разработке**:
  * **Раздел статистики в админке**: Заглушка статистики была полностью удалена со страницы `/admin`, так как панель статистики является частью отдельного проекта админки.
  * **Близкие коэффициенты (Close Odds)**: Функция "Похожие котировки в других БК" в карточке вилки еще не реализована (требуется эндпоинт на бэкенде агрегатора).
  * **Chrome Extension (PRO)**: Базовый фингерпринтинг работает, но UI-настройка резидентного прокси (`host:port:user:pass` через `chrome.proxy`) находится в бэклоге.
  * **Парсеры Pinnacle и Sbobet**: Выключены / требуют настройки прокси/VPN для обхода блокировок.

## 3. Telegram Mini App (`smartbet-mobile-app`)

### 3.1 Назначение и стек
Мобильная версия платформы, адаптированная для запуска внутри Telegram в качестве Mini App (Web App), а также подготовленная к сборке под Android/iOS.
* **Стек**: Next.js 14, `@twa-dev/sdk` для интеграции с Telegram API, `@capacitor/core` и `@capacitor/cli` для сборки нативных приложений, Framer Motion, Lucide-React.

### 3.2 Функциональные возможности
* **Список вилок**: Адаптивный интерфейс для просмотра найденных арбитражных ситуаций в реальном времени.
* **Фильтры**: Настройка фильтрации по регионам и режимам игры (Live / Prematch).
* **Мобильный кошелек (`TgWalletDashboard`)**: Упрощенный интерфейс для контроля виртуальных балансов букмекеров на ходу.
* **История коэффициентов**: Всплывающее окно `OddsHistoryModal` для отслеживания движения линии.
* **Интеграция с Telegram SDK**: Поддержка тактильной отдачи (Haptic Feedback) при тапах и переходах.

### 3.3 Текущий статус
* 🟢 **Что работает**:
  * Отображение списка прематч вилок и карточек `TgArbCard`.
  * Управление виртуальным кошельком в Telegram.
  * Фильтр по регионам.
  * Haptic Feedback при кликах через SDK Telegram WebApp.
  * Кнопка подписки на уведомления с перенаправлением в бота.
* 🔴 **Что НЕ работает / в разработке**:
  * **Live-режим**: При переключении фильтра на "Live" отображается заглушка:
    > 🔴 *Live-режим в разработке. Мы настраиваем прямую трансляцию данных.*
    *(Это связано с тем, что мобильное приложение пока не поддерживает WebSocket-соединение с aggregator-api).*

## 4. Telegram Bot (`igaming-bot-telegram`)

### 4.1 Назначение и стек
Служба взаимодействия с пользователем в мессенджере. Позволяет управлять фильтрами, покупать подписку за Telegram Stars и отправляет пуш-сигналы в каналы.
* **Стек**: Java, Spring Boot, `telegrambots-spring-boot-starter` (Long Polling), интеграция с микросервисом авторизации `auth-microservice` и агрегатором.
* **Развертывание**: K8s под именем `igaming-bot-telegram` (env: `TELEGRAM_ENABLED=true`, `THREADS_ENABLED=false`).

### 4.2 Функциональные возможности
* **Авторизация**: Автоматическая регистрация и генерация JWT-токена пользователя при первом запуске (`/start`) через `auth-microservice`.
* **Запуск Mini App**: Интеграция кнопки `WebAppInfo` для мгновенного открытия Mini App.
* **Региональные фильтры**: Интерактивная клавиатура для выбора отслеживаемых регионов.
* **Покупка Premium**: Поддержка оплаты подписки через Telegram Stars (`100 Stars` за Premium-доступ) с обработкой `PreCheckoutQuery` и `SuccessfulPayment`.
* **Push-рассылка**: Планировщик `NotificationScheduler` каждые 30 секунд проверяет новые вилки и отправляет лучшие предложения в официальный канал `@smartbetguru`.

### 4.3 Текущий статус
* 🟢 **Что работает**:
  * Авто-регистрация пользователей и синхронизация их премиум-статусов.
  * Обработка команд `/start`, `/arbs`, `/filters`, `/subscribe`, `/help`.
  * Оплата подписки через Telegram Stars.
  * Успешное получение вилок из агрегатора и регулярная публикация в канал.
* 🔴 **Что НЕ работает / Ошибки в логах**:
  * **Ошибка `EditMessageCaption` (Bad Request)**: При удалении или изменении статуса истекшей вилки бот пытается вызвать метод `EditMessageCaption` для сообщений, отправленных обычным текстом (без фото). Это вызывает ошибку:
    > `[400] Bad Request: there is no caption in the message to edit`
    *Решение*: Нужно проверять тип сообщения или использовать `EditMessageText` для текстовых постов.
  * **Сбой эндпоинта превью матчей**: В логах планировщика `MatchPreviewScheduler` зафиксирована ошибка `400 Bad Request` при обращении к агрегатору:
    > `Failed to fetch enriched upcoming matches from aggregator: 400 Bad Request from GET http://igaming-aggregator:80/api/matches/enriched-upcoming`
    *Решение*: Проверить параметры запроса или наличие данного эндпоинта на стороне `igaming-aggregator-api`.

## 5. Threads Bot (`igaming-bot-threads`)

### 5.1 Назначение и стек
Автономный модуль для публикации вилок с высоким профитом в социальную сеть Meta Threads с целью привлечения органического трафика в Telegram-канал.
* **Стек**: Java, Spring Boot, Meta Threads Graph API (создание контейнеров и публикация).
* **Развертывание**: K8s под именем `igaming-bot-threads` (env: `TELEGRAM_ENABLED=false`, `THREADS_ENABLED=true`).

### 5.2 Функциональные возможности
* **Фильтрация перед отправкой**: Публикуются только вилки с доходностью выше `minProfit` (по умолчанию 5.0%).
* **Форматирование постов**: Создание структурированных текстовых постов (до 500 символов) с эмодзи спорта (⚽, 🏀, 🎾), названиями команд, прибылью и реферальной ссылкой на Telegram-канал.
* **Двухэтапная публикация**:
  1. Создание контейнера поста: `POST /v1.0/{user_id}/threads`
  2. Публикация контейнера по ID: `POST /v1.0/{user_id}/threads_publish`
* **Авто-удаление вилок**: Планировщик отслеживает актуальность вилок и пытается удалить посты с неактуальными коэффициентами.

### 5.3 Текущий статус
* 🟢 **Что работает**:
  * Подключение к Meta Graph API по токену доступа.
  * Успешная генерация контейнеров постов и их публикация (зафиксированы успешные публикации, например, Post ID: `17977113456044477`).
  * Фильтрация вилок по минимальной прибыли.
* 🔴 **Что НЕ работает / Ошибки в логах**:
  * **Ошибка удаления постов (Код 10 - THApiException)**: При попытке удалить истекшую вилку Meta API возвращает ошибку 500:
    > `{"error":{"message":"Application does not have permission for this action","code":10,"type":"THApiException"}}`
    *Причина*: Токен приложения не обладает правами на удаление контента (требуются дополнительные scope, либо Threads API не поддерживает удаление через данный тип токена).
  * **Баг парсинга даты в clean-up таске**: При очистке старых постов (старше 2 дней) бот падает с ошибкой парсинга даты:
    > `Text '2026-06-06T09:18:12+0000' could not be parsed, unparsed text found at index 22`
    *Причина*: Шаблон даты в Java-парсер-коде не ожидает формат смещения зоны вида `+0000` (без двоеточия) или миллисекунд.
  * **Сбой эндпоинта превью матчей**: Аналогично Telegram-боту, планировщик `ThreadsMatchPreviewScheduler` получает ошибку `400 Bad Request` при попытке обратиться к `GET /api/matches/enriched-upcoming`.

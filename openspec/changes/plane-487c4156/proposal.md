# Proposal: [patron-content] Пайплайн публикации эксклюзивного контента для платных подписчиков (Boosty, Patreon, VK Donut, TG VIP)

## Context
- **Plane Task ID:** `487c4156-231e-4b0f-9d28-f3b3fd65a411`
- **Module:** Patron CRM & Community Feedback Hub (`SmartBet.guru`)
- **Blocked By:** `patron_ingest` (завершено)

## Problem Statement
Бесплатные каналы получают базовые обучающие посты и тизеры, однако для монетизации и удержания платной аудитории на платформах Boosty, Patreon, VK Donut и Telegram VIP требуется автоматизированный пайплайн дистрибуции эксклюзивного контента высокой ценности:
1. **Жирные связки и коридоры:** разбор вилок и коридоров с доходностью от 10% до 25% с детальным анализом лимитов и правил БК.
2. **Дайджест акций и фрибетов (80% кэша):** подборка свежих бонусов с пошаговыми инструкциями конвертации в реальные гарантированные деньги (согласно правилу #10 AGENTS.md).
3. **Мануалы по антифроду:** инструкции по прогреву браузерных профилей (Gecko/Camoufox), настройке мобильных прокси и работе с дроп-аккаунтами.

## Architecture & Platform Adaptations
- **Telegram VIP (@SmartBetVipBot):** отправка в закрытый VIP-канал защищенных постов с флагом `protect_content: true` (запрет пересылки, копирования и снятия скриншотов).
- **VK Donut:** публикация постов на стене сообщества с флагом `donut_paid_duration = -1` (постоянная эксклюзивность только для донов сообщества) через VK Wall API.
- **Boosty:** публикация закрытых статей с разграничением уровней доступа (min tier) через Boosty API.
- **Patreon:** публикация эксклюзивных англоязычных постов для USD-тиров ($25/mo Pro Arbitrageur, $100/mo VIP Syndicate) через Patreon API v2.
- **Оркестрация и планировщик:** единый диспетчер публикации контента с поддержкой ручного триггера через REST API и автоматического расписания.

## Definition of Done
1. Реализована поддержка публикации эксклюзивного контента во всех 4 модулях/адаптерах:
   - `igaming-boosty-bot` (эндпоинт и клиент публикации постов для подписчиков);
   - `igaming-vip-bot` (защищенные публикации `protect_content=true` в VIP-канал);
   - `igaming-vk-donut-bot` (публикация на стену для донов `donut_paid_duration=-1`);
   - `smm-agent` (`patreon_agent.py` и мультиплатформенный пайплайн публикации `patron_content_distributor.py`).
2. Покрытие юнит- и интеграционными тестами во всех затрагиваемых компонентах.
3. Проверка сборки и тестов (`mvn test`, `pytest`).

## 1. Схема взаимодействия компонентов

Современная экосистема разделена на изолированные Kubernetes-домены:
1. **`igaming-source`**: Слой сбора данных (40+ краулеров и лоадеров).
2. **`igaming-enrichment`**: Master Data Management (`igaming-mdm-service` :8095), приём данных из Kafka (`igaming-aggregator-ingestion`), сканер вилок (`igaming-aggregator-surebet`), нормализатор названий, SofaScore-мост.
3. **`igaming-api`**: Пользовательский API-шлюз (`igaming-portal` :8081/:80), агрегатор API (`igaming-aggregator-api` :80), фронтенд (`smartbet-guru` :3000, `sportvibe-today` :3000).
4. **`igaming-analytics`**: Квантовый аналитик (`igaming-ai-analyst` :8080), быстрый PyTorch инференс (`igaming-ml-inference` :8085), хранилище витрин ClickHouse (:8123), векторная база Qdrant (:6333), микро-профилирование составов (`igaming-match-vision` :8080).
5. **`igaming-master`**: Шина сообщений Kafka 3.7 (`kafka` :9092) и база пользователей `portal-postgres` (:5432).

# Proposal: [crowd-reddit] ИИ-агент крауд-маркетинга для Reddit (r/sportsbook, r/Arbing) с режимом прогрева

## Context
Plane Task ID: `7f025fda-e873-4e83-a563-53135c651702`

## Description
Разработка автономного ИИ-агента крауд-маркетинга для Reddit (`r/sportsbook`, `r/Arbing`, `r/sportsbetting`, `r/matchedbetting`) с обязательным режимом прогрева (Browser Cache Warmup & Organic Surfing) и соблюдением правил проекта SmartBet.guru:

1. **Режим прогрева (Warmup Pipeline, Rule 9)**:
   - Использование Firefox / Camoufox с персистентным контекстом (`launch_persistent_context`), строжайший запрет `new_context()`.
   - Персистенция профиля (`cookies.sqlite`, IndexedDB, LocalStorage) в Redis под ключом `smm:profile:reddit_<account_id>`.
   - Органический предсерфинг нейтральных ресурсов и веток Reddit с плавными движениями мыши Безье, паузами на чтение и человекоподобным скроллом перед выполнением целевых действий.

2. **Мониторинг сабреддитов и анализ релевантности**:
   - Отслеживание новых постов и комментариев в `r/sportsbook`, `r/Arbing`, `r/sportsbetting`, `r/matchedbetting`.
   - Семантическая фильтрация по ключевым паттернам (арбитраж, вилки, фрибеты, хеджирование, бонусы букмекеров, сканеры, коэффициенты).
   - Защита от спама и кулдауны: ограничение частоты ответов, дедупликация тредов, проверка кармы и безопасности аккаунта.

3. **Крауд-маркетинг и формула гарантированного кэша (Rule 10)**:
   - Органическая интеграция экспертных ответов с расчетами вилок и математического перекрытия бонусов.
   - Позиционирование фрибетов как 80% гарантированного кэша (SNR конвертация: `(K1 - 1)(K2 - 1) / K2 ~ 0.80`).
   - Автоматическая подстановка партнерских и трекинг-ссылок с UTM-метками (`utm_source=reddit&utm_medium=crowd`).

4. **Инфраструктура и сетевая топология (Rule 6)**:
   - Выделенный агент `smm-agent/reddit_agent.py` с поддержкой режимов CLI и демона.
   - Маршрутизация через кластерный HTTP-прокси `http://100.83.113.50:3128` (US-трафик через `outline-us`).
   - HTTP Healthcheck сервер (`/healthz`, `/actuator/health`) на порту 8080.
   - Манифест развертывания в Kubernetes `igaming-k8s/smm-bot-reddit.yaml`.
   - Полное покрытие модульными и интеграционными тестами (`smm-agent/tests/test_reddit_agent.py`).

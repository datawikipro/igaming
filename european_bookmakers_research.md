# Исследование: Интеграция европейских букмекерских компаний в платформу SmartBet.guru

В данном документе представлен детальный анализ европейских букмекерских компаний, доступных для интеграции в нашу платформу, с оценкой сложности разработки, стабильности API и покрытия рынков.

---

## 1. Сравнительный анализ кандидатов

Ниже приведена таблица сравнения основных европейских букмекеров, их технологических платформ и возможности интеграции парсеров.

| Букмекерская контора (БК) | Технологическая платформа / API | Сложность реализации | Стабильность работы | Покрытие рынков и преимуществ |
| :--- | :--- | :--- | :--- | :--- |
| **Unibet / 888sport / LeoVegas** | **Kambi Platform** (REST JSON API: `/listView` и `/event/{id}`) | **Низкая** (Чистый структурированный JSON) | **Высокая** (Минимум изменений в структуре API) | **Отличное**. Охватывает основные европейские лиги. Интеграция одной платформы позволяет легко запустить еще 4-5 БК. |
| **Betfair (Exchange & Sportsbook)** | **Betfair API-NG** (Официальный REST/JSON API с ключами) | **Средняя** (Требуется регистрация аккаунта разработчика и API-ключ) | **Очень высокая** (Официальное документированное API) | **Превосходное**. Betfair Exchange — мировой стандарт коэффициентов. |
| **Bwin / Sportingbet / Ladbrokes** | **Entain Platform** (REST API / WebSockets) | **Средняя** (Требуются заголовки авторизации/сессии и обход Cloudflare) | **Средняя** (Могут динамически менять структуру WebSocket-сообщений) | **Отличное**. Большой охват европейских игроков. |
| **Betsson / Betsafe** | **Betsson Group Platform** (REST API `/api/v1/fe/sportsbook`) | **Средняя** (Хорошо структурированный JSON, но агрессивная капча) | **Высокая** | **Хорошее**. Популярны в Северной и Восточной Европе. |
| **William Hill** | **Собственная платформа** (REST/JSON API) | **Средняя/Высокая** (Агрессивная защита Akamai/Cloudflare) | **Средняя** | **Хорошее**. Классический британский букмекер. |

## 2. Детальный разбор приоритетных вариантов

### Вариант 1: Платформа Kambi (Unibet, 888sport, LeoVegas) — **РЕКОМЕНДУЕТСЯ**
Kambi является крупнейшим B2B-поставщиком спортивных линий в Европе. Все БК на этой платформе используют единую структуру API, которая загружается напрямую на фронтенде их сайтов.

* **URL Листинга событий**:
  `https://eu-offering.api.kambi.com/offering/v2018/ub/listView/all/all/all/all.json?lang=en_GB&market=GB` (где `ub` — код бренда Unibet)
* **URL Деталей матча и коэффициентов**:
  `https://eu-offering.api.kambi.com/offering/v2018/ub/event/{eventId}.json?lang=en_GB`
* **Преимущества**:
  1. **Многократное использование кода (Multi-brand)**: Написав один базовый модуль `igaming-source-kambi`, мы сможем развернуть отдельные микросервисы для Unibet (`igaming-source-unibet`), 888sport (`igaming-source-888sport`), LeoVegas и Paf, просто переопределив базовый URL и идентификатор бренда в конфигурации.
  2. **Отсутствие шифрования / Чистый JSON**: Ответы от сервера Kambi приходят в виде отлично структурированных JSON-документов с готовыми ID исходов, именами команд и маркетами.
  3. **Простота маппинга**: Структура матчей полностью ложится на наши абстракции в `igaming-source-core`.

### Вариант 2: Betfair (Sportsbook / Exchange)
Betfair предоставляет официальный доступ к линии через Betfair API-NG. 

* **Особенности**:
  - Для работы требуется получить `Application Key` и сессионный токен через `POST /login`.
  - Доступны как спортивная биржа (Exchange), так и классический букмекер (Sportsbook).
* **Сложность**: Требует управления сессиями, авторизацией и оплаты коммерческого доступа (или лимитированного бесплатного доступа).

## 3. Выбор для реализации

Для старта реализации мы выбираем **Unibet** на платформе **Kambi** (модуль `igaming-source-unibet`).

### Архитектурная схема интеграции
1. **Модуль**: `igaming-source-unibet` (или родительский `igaming-source-kambi`).
2. **Тип интеграции**: REST API (HTTP GET-запросы к публичным шлюзам Kambi).
3. **Компоненты**:
   - `UnibetApiClient` — выполняет запросы к Kambi Offering API.
   - `UnibetDiscoveryService` — раз в 1-2 минуты опрашивает листинг событий `/listView/all/all/all/all.json` и сохраняет новые матчи в `match_cache` со статусом `PENDING`.
   - `UnibetOddsMapper` — преобразует JSON-ответ детального события в наш канонический `OddsUpdateRequest` с маппингом типов исходов (`BetType`).
   - `MatchService` — обрабатывает карточки матчей и передает данные в Kafka / REST эндпоинты агрегатора.
   - `MatchFetchScheduler` и `MatchLoadScheduler` — шедулеры для запуска циклов поиска и загрузки.

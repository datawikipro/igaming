# Proposal: [smm-meta] ИИ-агент активности для Threads и Instagram (Firefox Persistent Context + Cache Warmup)

## Context
Plane Task ID: `99c57d7f-2e08-4fcb-8984-a4c8594811f8`
Module: `smm-agent` / `igaming-k8s`
Rules: Rule 6 (Сетевая маршрутизация), Rule 9 (SMM Firefox/Camoufox, Запрет Инкогнито, Cache Warmup), Rule 10 (Фрибет = 80% гарантированных денег, Affiliate Radar)

## Description
Meta-платформы (Threads и Instagram) обладают чувствительными антифрод-системами, детектирующими CDP (Chrome DevTools Protocol) и мгновенно блокирующими учетные записи с чистыми сессиями (incognito) без накопленной истории и кэша.

В рамках задачи реализуется автономный ИИ-агент активности `meta_agent.py` (`MetaActivityAgent`), обеспечивающий:
1. **Firefox / Camoufox Persistent Context**:
   - Строжайший запрет на `new_context()`.
   - Использование `firefox.launch_persistent_context()` с сохранением полного профиля браузера (`cookies.sqlite`, `storage/default`, LocalStorage, IndexedDB).
2. **Персистентность сессий и профилей в Redis**:
   - Синхронизация архива профиля в Redis по ключам `smm:profile:<account_id>`.
   - Сохранение состояния сессии, токенов, таймингов и метрик активности в `smm:session:meta` (`smm:session:meta:<account_id>`).
3. **Обязательный прогрев кэша (Cache Warmup)**:
   - Предварительный органический серфинг 2–3 минуты по авторитетным новостным и спортивным порталам (BBC Sport, ESPN, Flashscore, Wikipedia) перед переходом на домены Meta.
   - Накопление HTTP-кэша, CDN-ассетов и локальной истории.
4. **Человекоподобная кинематика (Human Kinematics)**:
   - Движение курсора по кубическим кривым Безье со случайным боковым отклонением, сглаживанием smoothstep и микро-джиттером (тремором).
   - Естественные задержки чтения, интервальные паузы и реалистичный скроллинг ленты.
5. **Сетевая маршрутизация (Rule 6)**:
   - Проксирование через кластерный HTTP-прокси `http://100.83.113.50:3128`, автоматически перенаправляющий Meta-трафик в `outline-us` (`100.66.190.4`).
6. **Контент и конверсионная воронка (Rule 10)**:
   - Органический просмотр ленты Threads и Instagram (Explore / Feed).
   - Публикация постов с расчетом фрибетов по формуле 80% гарантированного кэша: $\eta = \frac{(K_1 - 1)(K_2 - 1)}{K_2} \approx 0.80$ (*«Фрибет 3 000 ₽ → 2 400 ₽ чистыми деньгами на счёт при любом исходе через вилку»*).
   - Партнерские реферальные ссылки с UTM-метками на SmartBet.guru.
   - Обязательный дисклеймер ответственной игры на всех маркетинговых публикациях: *«Ставки на спорт сопряжены с финансовыми рисками. Мы против лудомании и необдуманного беттинга. Играйте ответственно.»*
7. **K8s Деплоймент и мониторинг**:
   - Манифест `igaming-k8s/smm-bot-meta.yaml` в namespace `igaming-dev`.
   - Healthcheck сервер на порту 8080 (`/healthz`, `/actuator/health`).
   - Набор unit- и интеграционных тестов для проверки всех компонентов.

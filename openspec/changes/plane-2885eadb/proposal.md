# Proposal: [feedback-nlp] ИИ-классификатор, суммаризация обращений и генерация черновиков ответов (LLM Gateway)

## Context
Plane Task ID: `2885eadb-a10e-4c87-93da-d1e2ef7026e5`
Module: Patron CRM & Community Feedback Hub (`igaming-portal`)

## Description
Интеграция конвейера автоматической обработки входящей обратной связи на базе LLM Gateway:
1. **Категоризация обращений**:
   - `FEATURE_REQUEST` — пожелание / запрос нового функционала.
   - `BUG_REPORT` — ошибка в линии, баг калькулятора, проблема с авторизацией.
   - `QUESTION` — вопрос по тарифам, стратегиям вилкования, настройке прокси.
   - `PRAISE` — благодарность / положительный отзыв (кандидат в промо-материалы).
   - `NOISE` — спам, нерелевантный флуд, токсичные выпады без сути.
2. **Приоритеты и SLA**:
   - `P1_URGENT_PATRON` (SLA 15 мин): Платный VIP-патрон + Баг или Фича.
   - `P2_STANDARD_PATRON` (SLA 2 часа): Платный подписчик базового тарифа.
   - `P3_FREE_VALUABLE`: Бесплатный пользователь с конструктивной идеей.
   - `P4_FREE_NOISE`: Бесплатный спам/флуд (автоответ или архив).
3. **Суммаризация (`aiSummary`)**:
   - Сжатие длинного эмоционального текста в емкий тезис (до 100 символов).
4. **Генерация черновика ответа (`aiDraftReply`)**:
   - Вежливый, технически выверенный ответ с обращением по имени, благодарностью за донат/подписку и указанием дальнейших шагов.
5. **Отказоустойчивость и производительность**:
   - Время обработки < 2 секунд.
   - Высокоскоростной отказоустойчивый эвристический fallback-классификатор при недоступности внешнего LLM-шлюза.
6. **Тестирование**:
   - Пакет юнит-тестов на 20 эталонных сообщениях с точностью классификации > 90%.

## Context

Вслед за интеграцией североамериканского сегмента экосистема SmartBet.guru расширяется на рынки Латинской Америки (LatAm — Бразилия, Мексика, Колумбия), Европы и крипто-букмекеров.
В ходе сетевого аудита через `ru-proxy` (шлюз `outline-fi` в Нидерландах):
- **Betano** (Бразилия #1) и **Caliente** (Мексика #1) успешно открываются в Playwright с кодом HTTP 200 и отдают структурированные API.
- **Wplay**, **Codere**, **Tipico**, **Betdaq**, **BC.Game** и **SportyBet** отвечают HTTP 200 напрямую.
- Латиноамериканские лидеры Колумбии (BetPlay, Rushbet) и Европы (Unibet) работают на проверенном движке Kambi.

## Goals / Non-Goals

**Goals:**
- Разработка унифицированного модуля `igaming-source-playtech` для покрытия Caliente (Мексика) и Wplay (Колумбия).
- Разработка флагманского загрузчика `igaming-source-betano` для Бразилии.
- Подключение европейской биржи ставок `igaming-source-betdaq` для арбитража биржевых стаканов.
- Реализация B2B Odds API и партнерской CPA-переадресации в `igaming-portal`.
- Сохранение лимитов 512Mi на каждый PostgreSQL StatefulSet на сервере `xeon-srv`.

**Non-Goals:**
- Ночная перезагрузка сервера `xeon-srv` (22:00–10:00 МСК).
- Подавление высоких вилок и аномальных коэффициентов (Golden Rule #9: No Silent Drop).

## Decisions

### Decision 1: Унифицированный адаптер Playtech Sportsbook
- **Выбор**: Создать абстрактный модуль `igaming-source-playtech` и унаследовать от него `Caliente` и `Wplay`.
- **Обоснование**: Оба букмекера используют одинаковый протокол `web_nr` от Playtech. Написание одного парсера дает сразу 2 крупнейших рынка LatAm (Мексику и Колумбию).

### Decision 2: Монетизационная архитектура (CPA Redirector + B2B Odds API)
- **Выбор**: Добавить в `igaming-portal` модуль партнерской атрибуции `AffiliateRedirectController` и эндпоинты `B2BOddsApiController` с авторизацией по `X-API-Key`.
- **Обоснование**: Позволяет конвертировать не только подписчиков портала, но и монетизировать 100% бесплатного трафика через партнерские комиссии БК ($30–$150/депозит) и продавать потоковые данные синдикатам.

## Risks / Trade-offs

- **[Risk]** Гео-блокировки бразильских БК (EstrelaBet) по IP.
  - **Mitigation**: Подключение бразильского residential-узла при масштабировании на втором этапе; работа через Betano на первом этапе.
- **[Risk]** Нагрузка на сеть при высоких частотах опроса.
  - **Mitigation**: Оптимизация циклов опроса (1–2 секунды для Live, 15–30 секунд для Prematch) с компрессией GZIP/Brotli.

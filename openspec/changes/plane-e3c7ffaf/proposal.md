# Proposal: #46: [aggregator] Метрики и дашборд доходности вилок после расширения росписи маркетов

## Context
Plane Task ID: `e3c7ffaf-1b13-4787-a461-0bdb5cbd64f9`

## Problem Statement
В рамках предыдущих этапов (#41, #44, #45) была расширена роспись рынков для вилочного арбитража: добавлены исходы Чет/Нечет, Обе забьют (BTTS), периоды/сеты, киберспортивные карты CS2, угловые и желтые карточки, а также правила детекции структурных аномалий.
Для контроля стабильности, измерения эффективности и мониторинга качества арбитража в реальном времени необходимы:
1. Стандартизированные метрики Prometheus через Spring Boot Actuator (`/actuator/prometheus`) для отображения в корпоративной системе мониторинга (Grafana).
2. Телеметрия прироста вилок по видам спорта и типам рынков (с целевым подтверждением прироста >= +35%).
3. Гистограмма распределения доходности вилок (0-1%, 1-3%, 3-5%, 5-10%, 10%+).
4. Тепловая карта (матрица) пар букмекеров с наибольшим арбитражем для выявления наиболее профитных связок БК.
5. Внутренний REST API дашборда для оперативного анализа состояния сканера.

## Proposed Changes
1. **Prometheus & Web Actuator в `aggregator-surebet`**:
   - Добавление `spring-boot-starter-web` и `micrometer-registry-prometheus` в `aggregator-surebet/pom.xml`.
   - Включение веб-сервера на порту 8080 и экспозиция Actuator эндпоинтов `health`, `info`, `metrics`, `prometheus`.
2. **Сервис метрик `SurebetMetricsService`**:
   - `surebet_generated_total{market_type="...", sport="..."}` — счетчик сгенерированных вилок.
   - `surebet_active_gauge{market_type="..."}` — количество активных вилок в памяти/хранилище по типам рынков.
   - `surebet_yield_distribution` — гистограмма доходности вилок (бакеты 0-1%, 1-3%, 3-5%, 5-10%, 10%+).
   - `surebet_cross_bookmaker_matrix` — счетчик пар букмекеров с тегами `bookmaker_a`, `bookmaker_b`, `market_type`.
3. **Внутренний контроллер дашборда `SurebetDashboardController`**:
   - Эндпоинт `GET /api/v1/surebets/dashboard` с детализацией по доходности, маркетам, видам спорта и парам букмекеров.
   - Эндпоинт `GET /api/v1/surebets/metrics/summary` с агрегированными показателями и приростом росписи.
4. **Интеграция в пайплайн арбитража**:
   - Вызовы `SurebetMetricsService` при детекции в `SurebetRuleEvaluator`, при сохранении/удалении в `SurebetAlertManager` и по результатам сканирования в `SurebetDetectorService`.
5. **Тестирование и верификация**:
   - Комплексные unit-тесты метрик и контроллера.
   - Сборка OCI-образа через Jib, деплой в K8s `igaming-dev`, проверка `/actuator/prometheus` и 5-минутный тест стабильности (`schedule`).

## Impact & Capabilities
- Модуль `aggregator-surebet`: телеметрия Prometheus, REST API дашборда.
- Полная прозрачность доходности арбитражной экосистемы.

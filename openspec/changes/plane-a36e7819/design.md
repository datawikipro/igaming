# Design: [smm-runner] Базовый OCI-образ браузерного ИИ-агента

## Архитектура компонента `smm-runner`

### 1. Браузерный движок и запрет инкогнито (Rule 9)
- Meta (Threads, Instagram), Reddit и Cloudflare активно отслеживают сигналы автоматизации CDP (Chrome DevTools Protocol).
- Базовый стек: Playwright с движком **Firefox** и надстройкой **Camoufox** (Gecko).
- Метод запуска: строго `playwright.firefox.launch_persistent_context(user_data_dir=...)` или `camoufox.AsyncCamoufox(...)`.
- Использование `browser.new_context()` запрещено на уровне архитектуры.

### 2. Синхронизация сессий в Redis (`smm:profile:<account_id>`)
- При старте контейнера агент проверяет наличие сохраненного архива профиля в Redis.
- Если архив найден: распаковывается в `$USER_DATA_DIR` (включая `cookies.sqlite`, `storage/default/` с IndexedDB и LocalStorage).
- По завершении сессии или периодически: профиль пакуется в `tar.gz` и сохраняется в Redis с TTL (например, 30 дней) либо обновляет персистентный Volume.

### 3. Эмуляция человеческого поведения
- **Кубические кривые Безье**: генерация промежуточных точек перемещения курсора от $(x_0, y_0)$ до $(x_1, y_1)$ со случайными контрольными точками $P_1, P_2$, эмулирующими неравномерное ускорение и микро-дрожание человеческой руки.
- **Человеческий ввод**: случайные задержки между нажатиями клавиш (50–180 мс), случайные опечатки с исправлением (backspace) по настраиваемому флагу.
- **Естественный скролл**: плавный скролл страницы с паузами для "чтения" контента.

### 4. Модуль прогрева кэша (`cache_warmup.py`)
- Перед переходом к целевому домену (например, `threads.net` или `reddit.com`) агент выполняет 2–3 минуты серфинга по нейтральным спортивным и новостным порталам (`espn.com`, `bbc.com/sport`, `flashscore.com`, `wikipedia.org`).
- Создает реалистичную историю посещений, заполняет HTTP-кэш и куки рекламных сетей, снижая подозрительность IP и цифрового отпечатка.

### 5. Сетевая маршрутизация (Rule 6)
- Прокси по умолчанию: `http://100.83.113.50:3128` (кластерный `ru-proxy`, который прозрачно направляет американский трафик через `outline-us` `100.66.190.4`).
- Настраивается через переменные окружения `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` и параметры Playwright `proxy={"server": ...}`.

### 6. Удаленный доступ и отладка (noVNC + Xvfb)
- Виртуальный дисплей `Xvfb :99 -screen 0 1280x800x24`.
- Легковесный менеджер окон `openbox`.
- Сервер `x11vnc` на порту 5900.
- Веб-мост `websockify` на порту 6080 для подключения через браузер по noVNC.

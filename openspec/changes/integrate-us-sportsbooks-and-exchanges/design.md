## Context

Экосистема SmartBet.guru развернута на сервере `xeon-srv` (128 ГБ RAM, K8s namespace `igaming-source` и `igaming-dev`). 
Сетевая маршрутизация на узле `ru-proxy` (`100.83.113.50`) успешно обновлена и выпускает трафик через US Gateway (`outline-us` `100.66.190.4` в Айове, США, внешний IP `34.9.20.96`).
В ходе предварительного аудита 30 платформ США установлено:
- 18 платформ отвечают HTTP 200 сразу (включая гиганта Bovada с 4.78 МБ открытого JSON, биржи Sporttrade, ProphetX, Novig и шарпов Circa Sports и BookMaker.eu).
- 6 платформ успешно открываются через Playwright Chromium со stealth-маскировкой.
- Ряд платформ (Fanatics, Hard Rock, BetMGM) временно требуют Residential US IP из-за блокировки датацентров GCP.

## Goals / Non-Goals

**Goals:**
- Системное поэтапное подключение 30+ американских платформ (традиционные БК, биржи ставок, DFS/sweepstakes).
- Разработка и запуск флагманского загрузчика `igaming-source-bovada` в профиле `BASIC` с наполнением `match_cache >= 500`.
- Подключение американских P2P-бирж ставок (Sporttrade, ProphetX, Novig) для получения стаканов заявок с нулевой маржой.
- Подключение DFS/Player Props платформ (PrizePicks, Underdog Fantasy, Fliff) для арбитража на показателях спортсменов.
- Подключение глобального азиатского брокера (BetInAsia / OrbitX Betfair White Label) для замыкания глобального треугольника арбитража.
- Сохранение жестких ограничений по памяти: не более 512Mi на БД, использование легковесных Java 21 сервисов без раздувания Chromium-подов.

**Non-Goals:**
- Перезагрузка хоста `xeon-srv` в ночное время (22:00–10:00 МСК).
- Ограничение доходности или подавление аномальных коэффициентов (Golden Rule #9: No Silent Drop).
- Хардкод IP-адресов в коде или K8s-манифестах (только K8s DNS Service Names).

## Decisions

### Decision 1: Выбор Bovada (`bovada.lv`) в качестве флагманского MVP
- **Выбор**: Реализовать `igaming-source-bovada` в первую очередь.
- **Обоснование**: Открытый REST API отдает 4.78 МБ структурированных данных за 1 запрос, не требует сессий, кук и браузера. Потребление RAM минимально (~150 МБ против ~1.5 ГБ у Playwright). Обеспечивает мгновенное наполнение линии от 1,500+ матчей по 7 видам спорта.
- **Альтернативы**: DraftKings (требует обхода частых ротаций сессий), FanDuel (DataDome защита).

### Decision 2: Приоритет P2P-бирж ставок перед рекреационными БК
- **Выбор**: Параллельно с Bovada подключить американские биржи `Sporttrade`, `ProphetX`, `Novig`.
- **Обоснование**: Биржи имеют маржу 0–1.5%, стаканы Back/Lay и никогда не режут максимумы. Они служат идеальным вторым плечом для вилок против перекошенных линий рекреационных букмекеров.
- **Альтернативы**: Подключать только классические БК (приводит к риску быстрой порезки счетов).

### Decision 3: Двухуровневая маршрутизация (Datacenter Egress vs Residential Egress)
- **Выбор**: 
  - Уровень 1 (Бесплатный/Текущий): `outline-us` в GCP Iowa (`34.9.20.96`) для 20+ платформ, не блокирующих датацентры.
  - Уровень 2 (Платный/Перспективный): Выделение пула Residential US IP только для адресов Fanatics, Hard Rock Bet, BetMGM.
- **Обоснование**: Экономит бюджет на резидентский трафик на 85–90%, пропуская тяжелый трафик через собственный безлимитный шлюз.

### Decision 4: Архитектура Player Props (DFS Pick'em)
- **Выбор**: Расширить `AbstractBetTypeMapper` поддержкой `StatType` (POINTS, REBOUNDS, ASSISTS, PASSING_YARDS, TOUCHDOWNS) с привязкой к реестру спортсменов `athlete_cache`.
- **Обоснование**: На рынках игроков в США букмекеры ошибаются в 5 раз чаще, чем на исходах матчей, что дает колоссальную доходность вилок (до 20–25%).

## Risks / Trade-offs

- **[Risk]** Накопление 30+ новых баз данных PostgreSQL на сервере `xeon-srv`.
  - **Mitigation**: Стандартизация всех StatefulSet на лимиты `512Mi` (requests `128Mi`) и включение `synchronous_commit = off` предотвращает перегрузку диска и OOM-киллер.
- **[Risk]** Cloudflare Turnstile на отдельных сайтах (BetOnline, Hard Rock).
  - **Mitigation**: Использование проверенного профиля `HEADLESS_STEALTH` с маскировкой `navigator.webdriver` и кэшированием `cf_clearance` кук.
- **[Risk]** Регулирование и гео-блокировки по штатам (NJ vs NV vs NY).
  - **Mitigation**: Приоритет отдается общенациональным платформам (Bovada, Fliff, ProphetX, Novig) и агрегированным линиям штатов.

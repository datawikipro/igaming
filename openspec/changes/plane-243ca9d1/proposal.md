# Proposal: [team-national-detect] Автоматическое распознавание национальных сборных, связывание с ISO-кодами стран и бекфилл БД

## Context
Plane Task ID: `243ca9d1-f4a5-4a33-9c9c-43656b22da1e`
Feature Branch: `feature/plane-243ca9d1`

## Description
Разработка механизма автоматического распознавания национальных сборных команд (`NationalTeamDetector`), связывания их со стандартизированными кодами стран ISO-3166 (`CountryIsoRegistry`) и векторными флагами, а также реализация сервиса и REST API для бекфилла существующей базы данных команд (`NationalTeamBackfillService`).

### Проблема и цели
1. В исторической базе данных агрегатора накоплены тысячи команд, для которых поле `is_national_team` не заполнено (`false` или `null`), отсутствует привязка к ISO-кодам стран (`country_code`) и ссылкам на флаги (`flag_url`).
2. Для корректной работы UI-компонентов (`TeamAvatar`, плашки стран, карточки матчей) и аналитических модулей требуется:
   - Детектировать национальные сборные по названиям на русском и английском языках (например: "Россия", "Spain", "Сборная Франции", "Germany U21", "Бразилия (до 20)", "USA Women");
   - Корректно отсекать клубные команды и ложноположительные совпадения (префиксы ФК, БК, ХК, клубы вроде "Реал Мадрид", "Бавария", "ФК Россиянка");
   - Извлекать возрастные категории (`U23`, `U21`, `U20`, `U19`, `U17`, `YOUTH`, `OLYMPIC`) и гендерный признак (`MALE`, `FEMALE`);
   - Связывать сборные с ISO-3166 кодами (Alpha-2, Alpha-3) и локализованными названиями стран;
   - Предоставить REST API для запуска бекфилла (с поддержкой режима `dryRun`) и тестового распознавания единичных названий.

### Затрагиваемые компоненты
- `aggregator-domain`:
  - `CountryIsoInfo`, `CountryIsoRegistry`: справочник стран и ISO-кодов;
  - `NationalTeamDetectionResult`: результат детекции с атрибутами страны, флагом и каноническим названием;
  - `NationalTeamDetector`: эвристический сервис распознавания сборных;
  - `NationalTeamBackfillService`: сервис пакетной классификации и бекфилла базы данных команд.
- `aggregator-api`:
  - `DataManagementController`: добавление эндпоинтов `/api/v1/management/teams/backfill-national-teams` и `/api/v1/management/teams/detect-national`.

# Proposal: [smm-runner] Базовый OCI-образ браузерного ИИ-агента (Firefox/Camoufox + Persistent Profile + Cache Warmup + US Proxy)

## Context
Plane Task ID: `a36e7819-1749-4359-8289-c80a0220264c`
Module: SMM & Stealth Browser Agents (`smm-agent`)

## Description
Создание базового специализированного OCI-образа и модулей раннера для автономных браузерных ИИ-агентов на базе движка **Firefox / Camoufox (Gecko engine)** с персистентными профилями (Persistent Context), обязательным прогревом кэша (Cache Warmup) и маршрутизацией через US-прокси:

1. **Firefox / Camoufox Gecko вместо Chromium**:
   - Полное исключение CDP (Chrome DevTools Protocol) и антифрод-маркеров автоматизации для безопасной работы с Meta (Threads, Instagram), Reddit и Cloudflare.
   - Запуск исключительно через `firefox.launch_persistent_context` с персистентной директорией профиля `user_data_dir`. Строгий запрет инкогнито (`new_context()`).
2. **Персистентность профилей в Redis**:
   - Архивирование и компрессия состояния браузера (`cookies.sqlite`, `storage/default` IndexedDB, LocalStorage, HTTP cache) в `.tar.gz`.
   - Автоматическая синхронизация с Redis по ключу `smm:profile:<account_id>`. При старте или перезапуске пода агент восстанавливает рабочий контекст и просыпается «прогретым».
3. **Модуль прогрева кэша (Browser Cache Warmup)**:
   - 2-3 минуты реалистичного предварительного серфинга по авторитетным новостным и спортивным порталам (ESPN, BBC Sport, Flashscore и др.).
   - Генерация реального кэша, кук и истории посещений перед переходом к целевым действиям в соцсетях.
   - Движения мыши по кубическим кривым Безье, микро-джиттер, естественные задержки скролла и ввода.
4. **Сетевая маршрутизация через US-прокси**:
   - Настройка кластерного прокси и US egress (`100.83.113.50:3128` / `100.66.190.4`).
   - Поддержка параметров прокси на уровне браузерного контекста.
5. **Виртуальный дисплей и интерактивная консоль**:
   - Запуск внутри виртуального экрана Xvfb с разрешением 1920x1080x24 / 1280x800x24.
   - Интеграция с x11vnc и websockify для экстренного доступа оператора (noVNC).

# Proposal: [smm-runner] Базовый OCI-образ браузерного ИИ-агента (Firefox/Camoufox + Persistent Profile + Cache Warmup + US Proxy)

## Context
Plane Task ID: `a36e7819-1749-4359-8289-c80a0220264c`

## Description
Создание специализированного OCI-образа и модульного фреймворка для автономных браузерных ИИ-агентов SMM на базе **Firefox / Camoufox (Gecko engine)** с поддержкой:
1. **Персистентных профилей (Persistent Context)**: категорический запрет инкогнито (`new_context()`), использование `firefox.launch_persistent_context()` с долговременным хранилищем.
2. **Синхронизации профилей в Redis**: автоматическая архивация и распаковка профиля (куки `cookies.sqlite`, IndexedDB `storage/default`, LocalStorage, Cache API) под ключом `smm:profile:<account_id>`.
3. **Обязательного прогрева кэша (Browser Cache Warmup)**: модуль предстартового серфинга по нейтральным спортивным и новостным порталам с эмуляцией человеческого поведения (движения мыши по кубическим кривым Безье, задержки ввода, скролл).
4. **Сетевой маршрутизации через US Proxy**: встроенная поддержка маршрутизации через кластерный HTTP-прокси `http://100.83.113.50:3128` (US egress через `outline-us` `100.66.190.4`) для обхода региональных ограничений Meta/Threads/Instagram/Reddit.
5. **Интерактивной отладки и решения капч**: поддержка виртуального дисплея Xvfb + noVNC веб-консоли (порт 6080) и модуля `captcha_solver.py`.

## Success Criteria
- [x] Модуль `browser_manager.py` реализует персистентный запуск Firefox/Camoufox, синхронизацию профилей в Redis, человекоподобные движения мыши (Безье) и проксирование US.
- [x] Модуль `cache_warmup.py` обеспечивает 2-3 минуты реалистичного серфинга по спортивным сайтам для наполнения кэша и истории перед целевыми действиями.
- [x] OCI Dockerfile включает все зависимости: Playwright Firefox, Camoufox, Xvfb, x11vnc, websockify, noVNC, OpenCV, Redis, скрипты раннера.
- [x] Модульные тесты `test_smm_runner.py` валидируют персистентность профилей, алгоритмы Безье, конфигурацию прокси и логику прогрева.
